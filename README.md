# NetOps

> 以拓扑学网络，以实验验原理，以画布沉淀知识。

NetOps 是面向网络工程师从入门到高级成长的中文优先网络拓扑学习网站。使用独立合成拓扑、开放式阶梯课程、通俗/专业双层讲解、外部 eNSP/EVE-NG 实验指导与自由画布/笔记；**不构建浏览器网络协议模拟器**。

当前为全新仓库的 V0.1 集成 MVP 派工阶段，尚未开发交付。负责人将通过 CodeArts /goal 按统一蓝图执行，一次完整提交，后续迭代 Bug 与课程。
